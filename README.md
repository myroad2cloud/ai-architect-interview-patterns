A practical interview-preparation knowledge base for Azure Architecture, Presales, Migration, Governance, AI, Delivery Leadership, and consulting scenarios.

## Question-bank model

Each topic should contain:

1. Concept in simple language
2. Memory hook or analogy
3. 60-second interview answer
4. Deep-dive answer
5. Presales/customer-discovery angle
6. Follow-up questions
7. Common mistakes
8. Practical scenario

This makes the repository useful both for last-minute revision and deeper interview practice.
