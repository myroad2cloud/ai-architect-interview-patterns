# Matilda Learning Lab

A free, public learning site for Azure migration assessment architects. It combines eight architecture lessons, a sourced Matilda Windows discovery pilot, RAPID versus Discover, practical application-grouping and wave-planning exercises, a quiz, and a security access matrix.

The Northstar Health case and all asset names are fictional. This is independent educational material, not an official Matilda Cloud product or a substitute for a licensed environment, approved access, or current vendor instructions.

The site is a static HTML/CSS/JavaScript application. No analytics or backend collects learner input. Lesson progress and checklist state stay in browser storage. The two exercise downloads are created locally in the browser.

Primary sources are linked in the site's **Sources & limits** section.
